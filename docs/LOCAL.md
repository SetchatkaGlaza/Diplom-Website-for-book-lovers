# Как запустить сайт у себя и всё проверить

Инструкция для Windows: команды вводятся в **Git Bash** (он ставится вместе с
[Git for Windows](https://git-scm.com/download/win)). Скопировал строку → вставил
в Git Bash → Enter. По одной за раз, не меняя порядок.

Что понадобится: интернет, Git, Node.js 22 LTS. Postgres, Docker и Visual
Studio ставить **не нужно** — база работает внутри Node (PGlite), данные лежат
в папке `.data`, которую сайт создаст сам.

---

## 0. Короткий путь (если не хочется ничего читать)

```bash
git clone https://github.com/SetchatkaGlaza/Diplom-Website-for-book-lovers.git
cd Diplom-Website-for-book-lovers
./start.sh
```

Открой `http://localhost:3000`. Всё. Остальное ниже — если что-то пошло не так
или нужен полный каталог, тесты и «как это проверить руками».

---

## 1. Один раз: поставить Node и проверить

```bash
node -v
npm -v
```

Первая строка должна начинаться с `v22` (годится и `v20`, но проект собран на
22). Если команда не найдена — поставь Node 22 LTS с <https://nodejs.org>,
закрой Git Bash, открой заново, проверь ещё раз.

---

## 2. Скачать проект

```bash
cd ~/Desktop
git clone https://github.com/SetchatkaGlaza/Diplom-Website-for-book-lovers.git
cd Diplom-Website-for-book-lovers
npm ci
```

- `cd ~/Desktop` — папка, куда будем качать (можно любую свою).
- `npm ci` — поставить зависимости. Идёт 1–3 минуты, качает из интернета.
  Делается **один раз** на компьютер.

> Если `npm ci` ругается на сертификаты или сеть — повтори. Если пишет
> `EBUSY`/`EPERM` — закрой редактор и антивирусный сканер папки, повтори.

---

## 3. Запустить сайт

```bash
./start.sh
```

Скрипт сам:
- проверит Node,
- поставит зависимости, если их нет,
- поднимет базу в папке `.data`,
- накатит схему и зальёт демо-данные (60 книг, 5 читателей, 3 клуба),
- запустит сервер.

В конце увидишь:

```
== Запускаю: http://localhost:3000 ==
{"message":"сервер запущен","meta":{"url":"http://0.0.0.0:3000"}}
```

Открой в браузере <http://localhost:3000>.

**Остановить:** `Ctrl+C` в том же окне Git Bash.
**Запустить снова:** `./start.sh` (или `npm start`, но тогда база будет в
памяти — см. раздел 4).
**Начать с чистой базы:** `./start.sh --reset`.

В Windows можно просто дважды щёлкнуть `start.bat` — он делает то же самое.

## 4. Как это устроено с базой (чтобы не путаться)

| Способ запуска | Где данные | Переживают перезапуск |
| --- | --- | --- |
| `./start.sh` | папка `.data/` | да |
| `npm start` | память процесса | нет — после `Ctrl+C` всё заново |
| `npm run dev` | память процесса, автоперезапуск кода | нет |

То есть: для проверки руками — `./start.sh`, для правки кода — `npm run dev`.

Папка `.data` — это полноценная база Postgres в одном каталоге. Удалить её =
начать с нуля (`./start.sh --reset` делает это сам). В git она не попадает.

Посмотреть, что внутри, не запуская сайт:

```bash
ls .data
```

## 5. Тестовые записи: демо-читатели и вход

Демо-данные заливаются при первом запуске. У всех пяти читателей пароль
`reader2026`:

| Почта | Имя | Роль | Что показывает |
| --- | --- | --- | --- |
| `anna@example.com` | Анна | админ | админка, модерация, партнёрства, дайджест |
| `boris@example.com` | Борис | модератор | очередь жалоб |
| `vera@example.com` | Вера | читатель | полка, рецензии, статистика |
| `gleb@example.com` | Глеб | новичок | ограничения новичка (антиспам) |
| `dina@example.com` | Дина | читатель | клубы, подписки |

Вход: <http://localhost:3000/vhod>.

Письма локально **не отправляются** — они печатаются в окно Git Bash. Поэтому
регистрация нового аккаунта просит подтвердить почту, а письмо «приходит» в
лог: найди там ссылку и открой её. Для проверки проще входить демо-аккаунтом.

## 6. Полный каталог: 345 книг вместо 60

Демо-сид даёт 60 книг — чтобы сервер стартовал за секунды. Боевой каталог
(345 книг, 20 подборок, 10 авторов, 34 статьи, 4 клуба) лежит в `content/` и
заливается отдельной командой:

```bash
DB_DRIVER=pglite PGLITE_DATA_DIR="$PWD/.data" npm run content:load
```

Ожидаемый вывод:

```
[контент] проверка пройдена: 345 книг, 20 подборок, 10 авторов, 4 клуба
[контент] книги: создано 285, обновлено 0, пропущено 60
[контент] в базе: { books: 345, collections: 20, authors: 10, withDescription: 345 }
```

**Важно:** перед этой командой останови сайт (`Ctrl+C`), иначе база занята и
команда будет ждать. После — снова `./start.sh`.

Проверить контент, ничего не записывая:

```bash
DB_DRIVER=pglite PGLITE_DATA_DIR="$PWD/.data" npm run content:check
```

Обновить описания и годы у уже залитых книг (после правки `content/books.json`):

```bash
DB_DRIVER=pglite PGLITE_DATA_DIR="$PWD/.data" npm run content:load -- --update
```

## 7. Как всё это проверить руками (сценарий на 15 минут)

Открой <http://localhost:3000> и пройди по списку. Слева — что сделать,
справа — что должно быть.

### 7.1. Внешний вид

| Действие | Ожидание |
| --- | --- |
| Открыть главную | тёмный герой «Читай. Считай. Обсуждай.», справа стопка настоящих обложек, они плавно всплывают |
| Прокрутить вниз | блоки появляются по очереди, а не все сразу |
| Навести мышь на книгу в каталоге | обложка чуть наклоняется за курсором и приподнимается |
| Открыть любую книгу | обложка «раскрывается» как книга в руках |
| Сузить окно до ширины телефона (F12 → Ctrl+Shift+M) | меню уходит в кнопку, полка в герое становится горизонтальной лентой, ничего не вылезает за экран |
| Включить в Windows «Уменьшение движения» → перезагрузить страницу | анимаций нет, но всё читается и работает |

### 7.2. Каталог и обложки

| Действие | Ожидание |
| --- | --- |
| `/knigi` | 60 (или 345) книг, у каждой своя обложка: цвет и узор зависят от жанра |
| Открыть одну книгу в двух вкладках | обложка одинаковая — она не случайная |
| `/avtory` | у каждого автора «экслибрис» с инициалами, именем и годами жизни |
| `/kluby` | у клубов баннеры с названием и числом участников |
| Клик правой → «Открыть картинку в новой вкладке» на обложке | адрес вида `/kartinki/oblozhka/...` и это **PNG** |

### 7.3. Читательский дневник (войти как Вера)

| Действие | Ожидание |
| --- | --- |
| Войти `vera@example.com` / `reader2026` | в шапке появилось имя и аватар-монограмма |
| Добавить книгу на полку «Читаю» | книга появилась в `/polka`, прогресс можно двигать ползунком |
| Поставить «Прочитано», указать страницы | обновилась статистика в `/statistika` |
| Написать рецензию с оценкой | рецензия видна на странице книги и в ленте `/lenta` |
| Подписаться на другого читателя | счётчик подписок изменился |

### 7.4. Клубы

| Действие | Ожидание |
| --- | --- |
| `/kluby` → открыть клуб → вступить | появился доступ к обсуждению |
| Написать сообщение с пометкой «спойлер» | текст скрыт под спойлером, пока не нажмёшь |

### 7.5. Админка (войти как Анна)

| Действие | Ожидание |
| --- | --- |
| `/admin` | сводка: пользователи, книги, жалобы |

## 8. Автотесты

```bash
npm test
```

Ожидание в конце:

```
# tests 324
# pass 324
# fail 0
```

Идёт 6–8 минут: поднимает настоящую базу и ходит по настоящим страницам.
Меньше по времени:

```bash
npm run test:unit          # быстрые проверки функций, секунды
npm run test:integration   # сценарии страниц
npm run test:coverage      # плюс покрытие
```

## 9. Частые проблемы

| Симптом | Причина и что делать |
| --- | --- |
| `./start.sh: Permission denied` | `chmod +x start.sh`, затем снова `./start.sh` |
| `node: command not found` | Node не установлен или Git Bash не перезапущен после установки |
| `EADDRINUSE: port 3000` | уже запущен другой сайт. `PORT=3001 ./start.sh` и открыть `http://localhost:3001` |
| Страница открылась, но «стили не грузятся» | открой `http://127.0.0.1:3000` вместо `localhost`, или очисти кэш (Ctrl+F5) |
| Команда `content:load` «висит» | сайт запущен и держит базу — останови `Ctrl+C` и повтори |
| После `Ctrl+C` пропали книги | запускал `npm start`, а не `./start.sh`: база была в памяти |
| Всё сломалось, хочу как было | `./start.sh --reset` — пересоздаст базу с демо-данными |
| Нужно обновить код после `git pull` | остановить, `npm ci` (если менялся `package.json`), `./start.sh` |

## 10. Git Bash: минимум команд

```bash
pwd                       # где я сейчас
ls                        # что в папке
cd ~/Desktop              # перейти в папку
cd ..                     # на уровень выше
git status                # что изменено
git pull                  # забрать свежий код из GitHub
git log --oneline -5      # последние коммиты
Ctrl+C                    # остановить запущенный сервер
```

Полная инструкция по деплою на настоящий домен — `docs/DEPLOY.md`,
переменные окружения — `docs/ENVIRONMENT.md`, что и как нарисовано —
`docs/BRAND.md`.
