- [x] 13.5. «Правообладателям»: форма обращения, e-mail pravo@knigomany.ru, срок ответа 48 часов
- [x] 13.6. Соглашение, политика конфиденциальности, правила сообщества (удаление аккаунта было на этапе 4)
- [x] 13.7. Тесты: 9 штук — жалоба скрывает контент и пересчитывает рейтинг, блокировка гасит сессию и не даёт войти, обращение правообладателя создаёт запись

**Готово, когда:** ни один пункт нельзя выполнить без прав; каждая жалоба оставляет след в журнале. — **выполнено:** обычный пользователь получает 403 в админке, каждое действие модератора пишется в `moderation_log`.

**Важные решения:**
- жалоба сама контент не скрывает — решает модератор, иначе одну жалобу можно использовать как оружие;
- блокировка увеличивает `session_epoch`: активные сессии гаснут сразу, а не после перезахода;
- модераторов и админов блокировать нельзя — иначе один взлом снимает всю защиту;
- `moderation_log` не привязан каскадом к пользователю: журнал должен переживать удаление аккаунта.

**Что осталось на этап 23:** настоящая отправка писем (сейчас обращение сохраняется в журнале и видно модератору).
