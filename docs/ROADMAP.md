# «Книгоманы 2.0» — мастер-план: от текущего репозитория до продукта с аудиторией и первой прибылью

**Версия:** 1.0 · **Дата:** 17 ноября 2026 · **Ветка:** `arena/073a38fa-diplom-website-for-book-lovers`

---

## 0. Как читать этот документ

План разбит на **8 фаз**. В каждой фазе есть:

- **Цель** — что должно стать правдой к концу фазы (проверяемый результат).
- **Работы** — конкретные пункты, по которым можно закрывать задачи.
- **Артефакты** — что физически появляется в репозитории/у вас на руках.
- **Критерий выхода** — без этого дальше идти нельзя.
- **Срок** — при 10–15 часах в неделю и с ИИ-ассистентом. Если работаете 5 часов — умножайте на 1,8.

Принципиальная установка: **не переписываем всё ради переписывания.** Фаза 0–2 — новый фундамент и новый продукт, фаза 3+ — рост. Старый код (`controllers/`, `views/`, `models/`) остаётся как референс для переноса бизнес-логики (модерация, импорт, каталог) до конца фазы 4, потом удаляется.

**Что уже сделано в ветке** (фундамент v2, ~1 000 строк): новый `package.json` (Express 5, helmet, connect-pg-simple), конфиг БД с пулом, 14 моделей в `src/models/` (пользователь, книга, полка с прогрессом, рецензии, лайки, комментарии, подписки, клубы, лента активности, цели, жалобы, уведомления), библиотеки: CSRF double-submit, сессии в Postgres, почта (Resend/SMTP/console), rate-limit, валидаторы, транслитерация в слаги, русские склонения и форматирование. Это «фундамент», на который ложатся фазы 1–2.

## 1. Куда мы идём: продукт в одном абзаце

> **Книгоманы** — читательский дневник с характером. Вы отмечаете, что читаете и на какой странице, получаете живую статистику своего чтения, находите людей с похожим вкусом и обсуждаете книги в клубах по главам. Мы не продаём книги, поэтому рекомендуем честно.

Три опоры, которых нет у текущей версии и которые дают причину возвращаться:

1. **Дневник чтения** — прогресс, даты, «бросил», перечитывание, полка, цели. Данные, которые жалко потерять.
2. **Статистика** — «мой книжный год», месяцы, жанры, темп, серии дней. Эмоция + повод поделиться.
3. **Люди** — подписки, лента «что читают те, кого я читаю», клубы с расписанием и обсуждением по главам.

**North Star метрика:** `WAL` — Weekly Active Loggers: сколько людей за неделю отметили прогресс хотя бы по одной книге. Не регистрации, не просмотры. Это единственная метрика, которая коррелирует с деньгами.

**Позиционирование против конкурентов:** LiveLib — каталог и отзывы при магазине «ЛитРес»; мы — инструмент и сообщество без торгового интереса. StoryGraph — лучший трекер, но только на английском; мы — то же качество инструмента для русских книг и русскоязычных читателей.

## 2. Дизайн-концепция (делаем до кода экранов)

Прежде чем писать шаблоны, фиксируем визуальный язык. Иначе получится «ещё один градиентный сайт» — как сейчас.

**Идея:** «читательский дневник, а не витрина». Тёплая бумажная палитра, крупная типографика, много воздуха, ощущение личного кабинета, а не магазина.

| Элемент | Решение |
| --- | --- |
| Палитра | Фон `#F7F4EE` (бумага), текст `#1F1C18` (чернила), акцент `#2F5D50` (глубокий зелёный), второй акцент `#B4603A` (терракота), линии `#E3DCD0` |
| Тёмная тема | `#16130F` фон, `#EDE7DB` текст, тот же зелёный в осветлённом варианте |
| Типографика | Заголовки — крупная антиква (Georgia / «Literata» локально), текст — системный sans (Inter/`-apple-system`) |
| Сетка | 12 колонок, максимум 1180 px, плотность «воздушная»: 8 px шкала отступов |
| Компоненты | Корешок книги как основной визуальный образ, «карточка дневника», степпер прогресса, полоска статистики, чипы жанров |
| Движение | Только функциональное: появление карточек при скролле, плавный прогресс-бар. `prefers-reduced-motion` уважается |
| Мобайл | Проектируем сначала мобильный: нижняя навигация, свайп по статусам полки, крупные тач-цели ≥ 44 px |
| Иконки | Свой SVG-набор (12–15 иконок), без Font Awesome с CDN — скорость и единый стиль |
| Скорость | Только системные/локальные шрифты, критический CSS инлайном, `loading="lazy"` и `srcset` для обложек, без сторонних JS |

**Артефакты фазы дизайна:** палитра и токены в `public/css/tokens.css`, стайлгайд-страница `/styleguide` (видна только в dev), макеты 8 ключевых экранов (главная, каталог, книга, полка, профиль, статистика, клуб, онбординг).

### Фаза 2. Ядро продукта: дневник, полка, книга, рецензии
**Срок:** 3–4 недели · **Это главная фаза: именно она превращает каталог в продукт**

**Цель:** пользователь может пройти путь «нашёл → читаю → отмечаю → оценил → написал» без трения, и всё это приятно выглядит.

Работы:
- [ ] **Главная v2:** для гостя — «как это работает» + живые данные сайта + вход в каталог; для пользователя — «продолжить чтение», цель, лента, рекомендации
- [ ] **Каталог:** поиск по названию/автору (trigram), фильтры «жанр, длина, год, рейтинг», сортировки, пагинация, состояние фильтров в URL, пустые состояния
- [ ] **Страница книги:** обложка, метаданные, средний рейтинг и распределение, «сейчас читают N человек», кнопки полки, рецензии с лайками и комментариями, похожие книги, цитаты
- [ ] **Полка:** 4 статуса (`хочу`, `читаю`, `прочитано`, `бросил`), прогресс страниц/процентов, даты начала и завершения, перечитывание, избранное, фильтры и сортировки, массовые действия
- [ ] **Отметка прогресса:** быстрая форма «я на странице N» + «дочитал»; обновление без перезагрузки; пересчёт агрегатов книги
- [ ] **Рецензии:** создание с половинками звёзд, спойлер-флагом, черновиком; редактирование; пост-модерация по уровню доверия; жалобы; лайки; комментарии
- [ ] **Профиль:** публичный (аватар, био, статистика, полка, рецензии, подписчики) и приватный (настройки, цели, экспорт)
- [ ] **Подписки:** подписаться/отписаться, счётчики, «похожие читатели»
- [ ] **Лента:** события людей, на которых подписан; фильтры «рецензии / дочитали / полка»
- [ ] **Уведомления:** колокольчик со счётчиком, страница, отметка прочитанным, без опроса каждые 30 секунд (обновление по фокусу вкладки)

**Критерий выхода:** 100% сценариев «добавить книгу → отметить прогресс → дочитать → написать рецензию → получить лайк» работают на мобильном и десктопе; ни одна страница не делает больше 12 SQL-запросов.

### Фаза 3. Онбординг, импорт и активация
**Срок:** 1,5–2 недели

**Цель:** новый пользователь получает ценность в первые 3 минуты, а переезд с LiveLib не требует ручного ввода 200 книг.

Работы:
- [ ] Онбординг в 4 шага: имя/аватар → 5 любимых книг (поиск с автодополнением) → жанры → цель на год
- [ ] Из «любимых книг» сразу строятся рекомендации и заполняется полка «прочитано»
- [ ] **Импорт из LiveLib/Goodreads** (CSV): загрузка файла, сопоставление колонок, предпросмотр, отчёт «добавлено / не найдено / дубли»
- [ ] Массовое добавление книг: «отметить всё прочитанным» для серии
- [ ] Пустые состояния-«учителя»: что делать дальше на каждом экране
- [ ] Письма: подтверждение адреса, приветственное с советами (день 0), «как дела с книгой» (день 3)
- [ ] Опционально: импорт из Telegram-канала (парсинг списка книг текстом)

**Критерий выхода:** активация (3 книги + 1 прогресс или рецензия за 7 дней) ≥ 35% на тестовой группе из 20 человек.

### Фаза 4. Статистика и «Книжный год» — вирусная механика
**Срок:** 2 недели

**Цель:** появляется то, чем хочется поделиться и ради чего возвращаются в декабре.

Работы:
- [ ] Страница «Статистика»: книг и страниц за год/месяц, средний темп, лучший месяц, любимые жанры и авторы, средняя оценка, серия дней чтения, самый длинный и самый короткий том, «бросил» против «дочитал»
- [ ] Графики без библиотек: SVG-столбики месяцев, кольцо жанров, «тепловая карта» дней чтения
- [ ] **«Мой книжный год»**: отдельная страница-открытка, генерируемая на сервере в PNG (без внешних сервисов) — для сторис и постов
- [ ] Цели: годовая цель, прогресс, прогноз «при текущем темпе вы дойдёте к…»
- [ ] Достижения (10–12 штук): первая рецензия, 10 книг, 1000 страниц, серия 7 дней, «разнообразный год»
- [ ] Публичный профиль показывает «книжный год» — мотивация заполнять

**Критерий выхода:** ≥ 15% активных пользователей открывают статистику хотя бы раз в месяц; ≥ 5% делятся картинкой (замер по клику «скачать»).

### Фаза 5. Клубы и совместное чтение — удержание
**Срок:** 3 недели

**Цель:** людям есть зачем возвращаться каждую неделю, а не только когда они дочитали книгу.

Работы:
- [ ] Клубы: создание, обложка, описание, приватность, участники, роли (ведущий/участник)
- [ ] «Книга месяца» клуба: текущая книга, расписание по главам, дата обсуждения
- [ ] Обсуждение по главам: пост с меткой главы и спойлер-флагом, скрытие до «показать спойлер»
- [ ] Записи «живых» встреч: анонс, ссылка, итоги
- [ ] Каталог клубов: по жанрам, по активности, «найти клуб под себя»
- [ ] Совместное чтение вдвоём (buddy read): приглашение, общий прогресс
- [ ] Уведомления клуба: новое обсуждение, начало книги месяца, упоминание
- [ ] Инструменты ведущего: закрепить пост, закрыть обсуждение, исключить участника

**Критерий выхода:** 4 клуба с ≥ 10 участниками и ≥ 20 сообщениями; ≥ 30% MAU состоят хотя бы в одном клубе.

### Фаза 6. Модерация, безопасность проды и SEO
**Срок:** 2 недели

**Цель:** сайт можно открыть публично и не бояться ни спама, ни потери данных, ни поисковиков.

Работы:
- [ ] **Пост-модерация:** уровни доверия (0 — проверка первой рецензии, 1 — автопубликация после 2 одобрений, 2 — доверенный), автоскрытие после 3 жалоб, очередь модерации с приоритетом
- [ ] Жалобы: форма, причины, статусы, решения, уведомление автору; апелляция
- [ ] Админка v2: пользователи (роли, блокировка, сброс пароля), книги (CRUD, ISBN, жанры, обложки), рецензии, клубы, жалобы, метрики продукта
- [ ] Антиспам: rate-limit по действиям, honeypot, минимальное время на форму, блокировка ссылок у новичков
- [ ] **SEO:** `title`/`description` по шаблонам, canonical, OG/Twitter-карточки, JSON-LD (`Book`, `Review`, `Organization`), `sitemap.xml` (динамический), `robots.txt`, человекопонятные URL `/knigi/:slug`, страницы авторов и жанров
- [ ] **Прод-инфраструктура:** хостинг (Railway/Fly/VPS), Postgres с ежедневным `pg_dump` в объектное хранилище, Sentry, uptime-мониторинг, `helmet`+CSP, HTTPS, `trust proxy`, healthcheck `/healthz`
- [ ] Политика обработки ПД, согласие при регистрации, уведомление в РКН, правила сообщества, страница «как работает модерация»
- [ ] Нагрузочная проверка: 50 одновременных пользователей, индексы, N+1, кэш агрегатов

**Критерий выхода:** публичный запуск возможен: бэкап восстановлен на чистой БД, Sentry ловит ошибку, CSP не ломает сайт, `sitemap` отдаётся, модерация работает без ручного вмешательства в 80% случаев.

### Фаза 8. Рост, монетизация и первая прибыль
**Срок:** 3–4 месяца после запуска

**Цель:** продукт приносит деньги, а не только пользователей.

**Порядок монетизации (важно: именно в таком):**

1. **CPA-партнёрка магазинов** (технически 2 дня): кнопка «Купить» на странице книги, ссылки на «ЛитРес» (10–20%), Ozon (6–12%), «Читай-город». Метка `rel="sponsored"`, пометка «реклама», ERID через ОРД. Доход: 1–3 тыс. ₽/мес при 5 тыс. MAU — не бизнес, но бесплатно и не мешает.
2. **B2B-промо для издательств и самиздата** (первая реальная выручка): пакеты «книга дня», промо-страница, конкурс рецензий, подборка, рассылка. Цена 25–80 тыс. ₽ за кампанию. Медиакит с метриками, письмо-питч, 10 холодных писем в неделю. Это продажи, а не код — и именно здесь деньги.
3. **Премиум-подписка «Plus»** 249 ₽/мес или 1 990 ₽/год: расширенная статистика и сравнение годов, экспорт, приватные клубы, ранний доступ, без промо-блоков. Нужна платёжка (ЮKassa/Paddle), оферта, чеки.
4. **События и клубы**: встречи с авторами, платные клубы, доля автору.
5. **B2B-клубы для компаний** (год 2): «книжный клуб для сотрудников» по подписке.

Работы по монетизации:
- [ ] Страница «Plus» с оффером и таблицей сравнения
- [ ] Биллинг: подписка, пробный период 14 дней, управление, отмена, чеки
- [ ] Медиакит для издательств (PDF/страница) с цифрами: MAU, WAL, демография, форматы, цены
- [ ] CRM в Notion/Google Sheets для B2B-сделок: лид → пилот → договор → отчёт
- [ ] Отчёт для рекламодателя по кампании (показы, клики, переходы в магазин)
- [ ] Маркировка рекламы: поле `is_ad` у промо-блоков, ссылка на карточку ОРД, `sponsored`

**Юридический блок (обязательно до первых денег):** ИП/самозанятость и налоги с учётом вашего проживания в NL (нужна консультация бухгалтера: российское ИП с удалённым управлением либо NL-структура + Merchant of Record), оферта подписки, политика возвратов, политика ПД, договор с рекламодателем.

**Критерий выхода:** первая выручка ≥ 30–50 тыс. ₽/мес; доля платящих ≥ 2% MAU; 2 повторных B2B-контракта.
