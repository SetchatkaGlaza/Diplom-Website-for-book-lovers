# Переменные окружения: что нужно, а что можно не задавать

Один файл `.env` в корне. Скопируй `.env.example` и замени значения.
Ниже — что каждая строка делает, и что сломается, если её не заполнить.

## Обязательные в продакшене

Приложение само откажется стартовать, если чего-то из этого нет
(`src/config/env.js`), и напишет в журнал, чего именно не хватает.

| Переменная | Зачем | Пример |
|---|---|---|
| `NODE_ENV` | включает HSTS, secure-cookie, кэш статики, проверки окружения | `production` |
| `SESSION_SECRET` | подпись cookie сессии, минимум 32 символа | `openssl rand -hex 32` |
| `DATABASE_URL` | строка подключения к Postgres | `postgres://user:pass@host:5432/knigomany` |
| `PUBLIC_URL` | адрес сайта: письма, canonical, sitemap, редиректы с `www` | `https://knigomany.ru` |

`PUBLIC_URL` должен начинаться с `https://` — без него ссылка «подтвердить адрес»
в письме уведёт человека на localhost, и он не поймёт, что делать.

## Важные, но с запасным вариантом

| Переменная | Если не задать |
|---|---|
| `PORT` | 3000; хостинг обычно подставляет свой |
| `MAIL_FROM` | письма уйдут с `noreply@knigomany.ru`, часть почтовиков их отклонит |
| `RESEND_API_KEY` | письма только печатаются в лог — регистрация и сброс пароля не работают |
| `SMTP_HOST` / `SMTP_PORT` / `SMTP_USER` / `SMTP_PASS` | альтернатива Resend; если заданы оба, приоритет у Resend |
| `DB_SSL` | `true`; для облачных баз с обязательным TLS это верно, для локальной — поставь `false` |
| `LOG_LEVEL` | `info`; `error` — тише, `debug` — подробнее |
| `BCRYPT_ROUNDS` | 12 в продакшене, 4 в тестах |

## Только для разработки

| Переменная | Что делает |
|---|---|
| `DB_DRIVER=pglite` | Postgres в памяти процесса: `npm run dev` работает без установки базы, данные исчезают при остановке |
| `DB_SEED=false` | не заливать демо-данные при старте |
| `DB_RESET=true` | пересоздать схему перед стартом (данные пропадут) |
| `DB_MIGRATE=true` | накатить миграции при старте вместо отдельной команды |
| `DB_LOGGING=true` | печатать SQL-запросы |

## Как проверить, что окружение верное

```bash
# Продакшен-конфиг, но на localhost: приложение должно отказаться
# стартовать, если SESSION_SECRET / DATABASE_URL / PUBLIC_URL не заданы
NODE_ENV=production node src/server.js

# Полный список того, что видит приложение
node -e "console.log(require('./src/config/env').inspectEnv())"
```

Проверка занимает миллисекунды и не тратит деньги на хостинге: лучше
поймать опечатку дома, чем на проде в момент первого письма.
