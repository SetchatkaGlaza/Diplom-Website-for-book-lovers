# Книгоманы

**Читательский дневник**: полка, прогресс чтения, статистика, рецензии, цитаты,
лента друзей и клубы совместного чтения. Дипломный проект, переписанный с нуля:
старый сайт был каталогом с отзывами, новый — дневник, в который возвращаются.

- 18 пользовательских сценариев от гостя до удаления аккаунта
- 324 теста, покрытие 92% строк
- один сервер на Node.js + Postgres, без SPA и без сборки фронтенда

---

## Что умеет

### Гость
каталог с поиском и фильтрами · карточки книг с рецензиями · жанры ·
публичные профили · клубы · регистрация и вход · восстановление пароля ·
`/sitemap.xml` и `/robots.txt`

### Читатель
полка с четырьмя статусами · прогресс по страницам · цель на год ·
«Книжный год» картинкой PNG · рецензии со спойлерами · лайки и комментарии ·
цитаты · подписки и лента · личные сообщения · клубы по главам ·
импорт и экспорт CSV · уведомления · удаление аккаунта

### Модератор
жалобы · скрытие рецензий и сообщений · журнал решений, который переживает
удаление аккаунта автора

### Администратор
роли и блокировки · всё, что у модератора · статистика сайта

## Стек

| Область | Технологии |
|---|---|
| Сервер | Node.js 22, Express 5 |
| Шаблоны | EJS + express-ejs-layouts, без сборки |
| База | PostgreSQL, Sequelize, свои миграции |
| Сессии | express-session + Postgres-хранилище |
| Пароли | bcrypt (12 раундов) |
| Почта | Resend или SMTP, nodemailer |
| Картинки | sharp: обложки, аватары, портреты, PNG «Книжного года» |
| Тесты | `node --test` + supertest, база PGlite |
| Безопасность | helmet, CSP с nonce, CSRF на сессии, свои лимиты |

Зависимостей 16 в рантайме: нет ни сборщика, ни UI-фреймворка, ни ORM-обвязки.

## Быстрый старт

Нужен **только Node.js 20+**. Postgres, Docker и Visual Studio ставить не нужно.

```bash
npm ci          # зависимости, один раз
npm run dev     # база создастся сама, демо-данные зальются автоматически
```

Откройте <http://localhost:3000>. Вход: `anna@example.com` / `reader2026`
(админ), остальные читатели — `boris@`, `vera@`, `gleb@`, `dina@example.com`
с тем же паролем.

То же самое двойным щелчком: `start.bat` (Windows) или `./start.sh`.

**Как выбирается база.** По умолчанию проект пробует подключиться к Postgres,
а если тот не отвечает за 2,5 секунды — поднимает встроенную (PGlite), то есть
настоящий Postgres в WASM, с теми же миграциями и SQL. Данные лежат в папке
`.data` и переживают перезапуск. В журнале при старте написано, что выбрано:

```
{"message":"база: встроенная (PGlite)","meta":{"reason":"Postgres недоступен (…)"}}
{"message":"данные лежат в .data — удалите папку, чтобы начать с нуля"}
```

Принудительно: `DB_DRIVER=pglite` — только встроенная, `DB_DRIVER=postgres` —
только настоящий Postgres (в продакшене так и надо: молча подменять базу нельзя).

| Команда | Что делает |
|---|---|
| `npm run dev` | запуск с автоперезагрузкой |
| `npm start` | обычный запуск |
| `npm run doctor` | проверка окружения: Node, bcrypt, зависимости, база |
| `npm run db:reset` | удалить базу и залить демо-данные заново |
| `npm run db:migrate` | накатить схему |
| `npm run db:seed` | демо-данные (60 книг, 5 читателей) |
| `npm run content:load` | полный каталог: 345 книг, 20 подборок, 10 авторов |
| `npm test` | все тесты |
| `npm run check` | линтер + проверка шаблонов (инлайн-стили, alt, заголовки) |

Полный каталог на 345 книг (сайт лучше остановить):

```bash
npm run content:load
```

Подробная инструкция для Git Bash — **`docs/LOCAL.md`**: установка, тестовые
записи, сценарий проверки на 15 минут и разбор частых ошибок.

### С настоящим Postgres

```bash
cp .env.example .env       # заполнить DATABASE_URL и SESSION_SECRET
npm run db:migrate         # схема
npm run db:seed            # демо-данные (в продакшене не нужно)
npm run dev                # DATABASE_URL найден — встроенная база не включается
```

Если Postgres указан, но не отвечает, приложение остановится и скажет, что
именно не так (нет базы, неверный пароль, сервер не запущен) — вместо
стектрейса на три экрана.

## Тесты

```bash
npm test             # 324 теста, ~7 минут
npm run test:unit    # только утилиты, секунды
npm run test:coverage
```

Что покрыто: регистрация и вход · права гостя, читателя, модератора, админа ·
XSS, CSRF, перебор пароля, подделка файлов · гонки лайков и статусов ·
импорт CSV · PNG «Книжного года» · SEO и микроразметка · 18 сценариев приёмки ·
50 параллельных запросов и число SQL-запросов на страницу.

Тесты идут на PGlite, но через настоящие маршруты, шаблоны и middleware —
это ближе к продакшену, чем моки.

## Принципы, которые соблюдаются в коде

1. **Никаких полных текстов книг.** Только заметки и короткие цитаты: чужие
   тексты — это статья 1301 ГК, а цитата до 300–500 знаков с указанием автора
   законна.
2. **Сервер — единственный источник правды.** Проверки в браузере для удобства,
   а не для безопасности.
3. **Каждый ответ — с понятным текстом.** Ошибка 500 не показывает стек,
   но пишет его в журнал с `X-Request-Id`.
4. **Тесты проверяют поведение, а не реализацию.** Если код меняется, а человек
   видит то же — тест должен остаться зелёным.
5. **Личные разделы не индексируются.** Переписка и статистика закрыты
   и в `robots.txt`, и мета-тегом.
